Frequently asked

What is a DID on Bluesky?
A Decentralized Identifier (DID) is a unique, permanent ID for every user in the AT Protocol. Bluesky assigns each account either a did:plc (managed by the PLC directory) or a did:web (hosted on the user's own domain). Unlike handles, a DID never changes.
Where does the DID come from?
This tool calls the official Bluesky Public API endpoint com.atproto.identity.resolveHandle, which returns the DID for any valid handle. No credentials or authentication required.
Can I look up custom domain handles?
Yes. Enter any valid Bluesky handle, including those using a custom domain like user.example.com. The AT Protocol supports domain-based handles verified via DNS records.
What do I do with a DID?
DIDs are useful for developers building on the AT Protocol, for verifying identity across server migrations, and for constructing AT URIs to reference a user's content. You can also view a user's full DID document at plc.directory.
